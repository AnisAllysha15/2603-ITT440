## 1.0 Project Overview
This project investigates the performance bottlenecks associated with processing massive datasets in Python. By simulating a security audit on **600,000 passwords**, the application benchmarks three distinct programming architectures: **Sequential**, **Concurrent (Threading)**, and **Parallel (Multiprocessing)**. 

The primary goal is to demonstrate how a parallel architecture can bypass the Python Global Interpreter Lock (GIL) to utilize 100% of multi-core hardware for CPU-bound cryptographic tasks.
